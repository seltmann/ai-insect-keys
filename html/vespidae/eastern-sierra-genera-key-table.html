Eastern Sierra Vespidae Genus Key - Table View

Last updated: 2026-08-26

This table view is a specimen-sorting aid for the Eastern Sierra Vespidae genus key, using the same strict Inyo plus Mono County working scope. Read the rows as a table version of the dichotomous key: match the character state, then use the Result column as the identification or next step.

Rows marked "outside working fauna" are retained as guard rails because they appear in the source keys or adjacent faunas, but they are not part of the current strict Inyo plus Mono genus set.

Filtered Eumeninae Table For Current Specimens

Use this table after ruling out Eumenes, Zethus, Minixi, Zeta, and Monobia for the current material. Minixi and Zeta are not part of the current strict Inyo plus Mono draft; they are noted here only because they were explicitly ruled out during specimen triage.

Current tray note: specimens described as predominantly yellow with some black. Treat this as supporting evidence, not as the lead character. It is compatible with Pterocheilus and some other male Eumeninae, and it supports ruling out dark black-and-ivory Monobia, but the generic path should still start with tegula shape, pronotal pits/carinae, antenna, and metasomal tergum 1 and 2.
