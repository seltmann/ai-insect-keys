# Eastern Sierra Vespidae Genus Key - Table View

Last updated: 2026-08-26

This table view is a specimen-sorting aid for the Eastern Sierra Vespidae genus
key, using the same strict Inyo plus Mono County working scope. Read the rows
as a table version of the dichotomous key: match the character state, then use
the Result column as the identification or next step.

Rows marked "outside working fauna" are retained as guard rails because they
appear in the source keys or adjacent faunas, but they are not part of the
current strict Inyo plus Mono genus set.

## Filtered Eumeninae Table For Current Specimens

Use this table after ruling out `Eumenes`, `Zethus`, `Minixi`, `Zeta`, and
`Monobia` for the current material. `Minixi` and `Zeta` are not part of the
current strict Inyo plus Mono draft; they are noted here only because they were
explicitly ruled out during specimen triage.

Current tray note: specimens described as predominantly yellow with some black.
Treat this as supporting evidence, not as the lead character. It is compatible
with `Pterocheilus` and some other male Eumeninae, and it supports ruling out
dark black-and-ivory `Monobia`, but the generic path should still start with
tegula shape, pronotal pits/carinae, antenna, and metasomal tergum 1 and 2.

## Male Antenna Quick Check

| Antenna state | Genera to check | How to read it |
| --- | --- | --- |
| Apical flagellomeres flattened and coiled | `Odynerus` | Strongest "otherwise modified" condition in the current Eumeninae table; pair with rounded tegula, tergum 1 lacking transverse carina, and male mid femur with two deep ventral emarginations. |
| Apical flagellomeres not coiled, but flagellomere XI reflexed | `Ancistrocerus` | This can look hook-like; pair with pointed tegula and tergum 1 usually with a transverse carina. |
| Apical flagellomere modified or very small; antenna with 12 or 13 articles | `Pterocheilus` | Not the same as the `Odynerus` coil or `Ancistrocerus` reflexed flagellomere; pair with evenly rounded tegula, no epicnemial carina, and a developed pronotal transverse carina. |
| Antenna simple apically | `Symmorphus` | Useful negative check; pair with tergum 1 having a shallow median groove posterior to the carina and a well-defined omaulus. |
| Male antennal club, sometimes concave beneath | `Pseudomasaris` | Masarinae, not Eumeninae. This is a clubbed antenna condition rather than a hook/coiled apex. |
